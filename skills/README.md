# Local agent skills

These folders mirror [addyosmani/agent-skills](https://github.com/addyosmani/agent-skills) `skills/*/SKILL.md` for this repo. Attach in chat with `@skills/<folder>/SKILL.md` (for example `@skills/frontend-ui-engineering/SKILL.md`).

Folders: `code-review-and-quality`, `incremental-implementation`, `frontend-ui-engineering`, `shipping-and-launch`, `spec-driven-development`, `debugging-and-error-recovery`.

If this directory is missing on another machine, clone the repo and copy those six folders into `skills/`, or rerun your setup script from the same machine that has `~/agent-skills`.
